# Waste Collection Accessibility in Port Harcourt

This repository contains the project brief for a place-based GIS study of access to mapped waste-collection and waste-disposal points in Port Harcourt Local Government Area, Rivers State, Nigeria. The proposed analysis combines GRID3 administrative and settlement data with OpenStreetMap roads and waste-related amenities to identify settlement areas that are furthest from available waste infrastructure.

The full brief states one specific spatial question, names the study area, lists every required dataset, provides a source link beside each dataset, records the data-availability limitation, and describes the proposed GIS output.

Read the complete brief here: [project-brief.md](project-brief.md)

## Planned output

A reproducible QGIS workflow and map will rank settlement areas by distance to the nearest mapped waste point. Road-network distance or service areas will be used where the extracted road and waste-point data support that level of analysis.

## Important data note

OpenStreetMap coverage is community-maintained and may be incomplete. Waste-point coverage will be checked during extraction; the analysis will not treat an absence of an OSM point as proof that no formal facility exists.
